## Firestore 보안 규칙 (콘솔 → Firestore → 규칙, 기존 규칙 안에 아래 두 match 를 **추가**)
```
    match /lotto/{rid} {
      function lm() { return request.auth != null && exists(/databases/$(database)/documents/lotto/$(rid)/members/$(request.auth.uid)); }
      allow create: if request.auth != null;
      allow read, update, delete: if lm();
      match /members/{uid} {
        allow create: if request.auth != null && request.auth.uid == uid;
        allow read, update, delete: if lm();
      }
      match /{doc=**} { allow read, write: if lm(); }
    }
    match /lottoInvites/{code} {
      allow get, create, delete: if request.auth != null;
    }
```
(기존 `match /users/{uid}/{document=**}` 규칙이 `users/{uid}/lotto/room` 을 덮으므로 그대로 둔다. `lottoInvites` 는 목록(list)을 막고 코드를 아는 사람만 읽게 `get`.)
